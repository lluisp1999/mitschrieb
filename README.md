# Mitschrieb

Phone-friendly app for reviewing the vocabulary, grammar and sentences from each class of my German course
(flashcards, quiz, exercises, spaced repetition, practice archive).

This repository only holds the app. The lessons and my progress live in the private repository
`mitschrieb-data`; the app reads and writes it through the GitHub API with a personal access token
that each device keeps in its own browser storage.

- App: https://lluisp1999.github.io/mitschrieb/
- Files: `index.html` (the whole app), `sw.js` (offline shell), `manifest.webmanifest` and icons (home-screen install).
